The funniest one-line excuse a robot vacuum gives for missing a spot, for
the make.fun bounty "The Robot Vacuum's Best Excuse". The program writes a
single 129-character line to `/output/entry.txt`:

> My cliff sensor voted 3-2 that the corner was a staircase. I respect democracy, so I left the dust there and went home to charge.

## Run it

```sh
node main.ts
```
